# Mi portafolio

Portafolio personal de desarrollador de software, hecho con HTML, CSS y JavaScript puro (sitio estático, sin dependencias).

## Estructura
- `index.html` – inicio, habilidades y proyectos
- `about.html` – sobre mí y trayectoria
- `contact.html` – contacto
- `css/style.css`, `js/main.js`

## Probar en local
Abre `index.html` en el navegador, o ejecuta `python3 -m http.server 8000` y entra a `http://localhost:8000`.

## Despliegue
Repositorio en GitHub → Dokploy (Application, build type Static) → visible en la red local por la IP del servidor.
